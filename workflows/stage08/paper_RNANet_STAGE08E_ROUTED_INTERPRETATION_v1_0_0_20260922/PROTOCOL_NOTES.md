# Stage08E protocol notes

## What Stage08E can establish

Stage08E can summarize the performance of the already frozen routed system under the finalized Stage08D protocol.
The primary representation-substitution contrast is:

`routed calibrated system - Core partition-calibrated control`

This control keeps `C+HNM` in both domains but applies the same SURF/non-SURF calibration architecture. Therefore this contrast isolates the effect of replacing Core by the frozen Complete arm within the SURF domain more cleanly than comparison with one globally calibrated Core score.

Within the SURF test subset, AUPRC and AUC can also be compared directly between `ACS+HNM` and `C+HNM`, because each ranking metric is evaluated on the identical rows. Positive Platt slopes preserve within-domain ordering apart from negligible numerical ties.

## What Stage08E cannot establish

The five outer seeds are resampling repetitions, not five independent biological studies. Directional 5/5 consistency is useful robustness evidence, but an exact two-sided sign probability of 0.0625 for 5/5 should not be presented as conventional biological-unit statistical significance.

The frozen outer-test results had been viewed historically before Stage08B-08D were finalized. Stage08B/08C selection did not use outer-test metrics and Stage08D did not perform candidate selection, but the project-level test splits are not globally pristine external confirmation. Claims must therefore remain retrospective/frozen-protocol claims until a future untouched external set is evaluated.

No Stage08E result may be used to reopen arm selection or alter the routing rule.
